BUG-007 [HOCH][OFFEN] — hmac.new() deprecated / falsche API in 6 Dateien
  Dateien:
    app/routes/user_api.py        Zeile 98, 481
    app/routes/client_auth.py     Zeile 130, 147
    app/services/server_federation.py  Zeile 360, 392
  Ursache: hmac.new() ist in Python 3 nicht die empfohlene API.
           Korrekt ist: hmac.new(key, msg, digestmod) (Python3 Alias für hmac.HMAC)
           Die aktuelle Verwendung funktioniert noch, ist aber deprecated-style
           und könnte in zukünftigen Python-Versionen entfernt werden.
           WICHTIGER: Der Code übergibt die Parameter korrekt, aber ohne
           explizite digestmod-Benennung → fragil.
  Beispiel (user_api.py:98):
    expected_sig = hmac.new(
        webhook_secret.encode('utf-8'),
        body,
        hashlib.sha256
    ).hexdigest()
  Fix:
    expected_sig = hmac.new(
        webhook_secret.encode('utf-8'),
        body,
        digestmod=hashlib.sha256  # <- expliziter keyword-Arg
    ).hexdigest()
  Alle 6 Stellen anpassen (digestmod= als keyword arg)
  Impact: Niedrig aktuell, mittel langfristig (Python-Upgrade-Risiko)

BUG-012 [HOCH][OFFEN] — JWT Secret pro-Request neu generiert in user_api.py
  Datei:  app/routes/user_api.py Zeile 454
  Code:   jwt_secret = os.environ.get("JWT_SECRET", secrets.token_hex(32))
  Ursache: secrets.token_hex(32) wird bei JEDEM Aufruf der generate_jwt() Funktion
           neu ausgeführt wenn JWT_SECRET nicht in ENV gesetzt ist.
           → Jeder erzeugte JWT wird mit einem anderen Key signiert
           → Alle JWTs werden sofort ungültig sobald ein anderer Request kommt
           → Kompletter Authentifizierungs-Bypass möglich
  Fix:    JWT_SECRET als Modul-Level-Variable setzen (einmal beim Import):
          JWT_SECRET = os.environ.get("JWT_SECRET") or secrets.token_hex(32)
          Oder besser: Startup-Fehler wenn nicht gesetzt
  Impact: Kritisch für user_api JWT-Auth — alle Tokens ungültig nach erstem Request

  Dateien:

  Ursache: asyncio.get_event_loop() ist in Python 3.10+ deprecated wenn kein

  Impact: Info/Niedrig — DeprecationWarning in Python 3.12+, Fehler in 3.14+
