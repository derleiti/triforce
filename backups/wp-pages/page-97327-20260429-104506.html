🚀 First Steps

\n
# Login (einmalig)\naicoder login --email user@example.com\n\n# Agent REPL starten (interaktiver Modus)\naicoder\n\n# Oder direkt Aufgabe geben\naicoder agent "fix the bug in main.py"\n\n# Code Review\naicoder review -f app.py\n\n# Task mit Datei\naicoder task "Add error handling" -f server.py --apply\n\n# Modelle anzeigen (630+)\naicoder models --group
