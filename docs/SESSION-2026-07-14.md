### 1.1 uvloop/httptools waren weg — Ursache: google-antigravity

**Befund:** Der Server lief seit dem 13.07. **ohne uvloop und ohne httptools**
auf dem langsamen asyncio-Standardloop. `app/utils/performance.py` ruft
`setup_uvloop()` auf, das lief still ins Leere.

**Ursache (nachgemessen, nicht geraten):**
```
google-antigravity 0.1.6  Requires: absl-py, google-genai, mcp, protobuf, pydantic, uvicorn, websockets
                                                                               ^^^^^^^ ohne Extras
```
Beim `pip install google-antigravity` hat pip die Anforderung `uvicorn` (nackt) mit
`uvicorn[standard]` zusammengefuehrt und die Extras dabei **fallen gelassen**.
`requirements.txt` wurde anschliessend lokal auf `uvicorn>=0.46` geaendert — damit war
der Verlust festgeschrieben. cp314-Wheels existieren, es war kein Build-Problem.

**Fix:**
- `pip install 'uvicorn[standard]>=0.51'` -> uvloop 0.22.1, httptools 0.8.0, watchfiles 1.2.0
- `requirements.txt`: `uvicorn[standard]>=0.51` + Kommentar, der den Fallstrick benennt
- `google-antigravity` bleibt drin (Dev-Tooling), aber mit Warnhinweis dokumentiert
- Verifiziert: `setup_uvloop() -> True`, `pip check` sauber, 178 Tests gruen

**Wirksam ab dem naechsten Restart** (der laufende Prozess hat den alten Loop).

der Prozess-Env, kein `.secrets.json`. Der **Vault ist gesperrt**. Das ist die zweite
Haelfte der 401-Meldungen aus den Logs und braucht eine Entscheidung.

## 5. GELERNT

1. **Ein `pip install` kann Extras still abraeumen.** Wenn ein Paket `uvicorn` ohne
   Extras fordert und ein anderes `uvicorn[standard]`, gewinnt nicht automatisch das
   Superset — und `pip check` meldet nichts, weil formal nichts kaputt ist.
   Nach jedem Install eines fremden SDKs: `python -c "import uvloop, httptools"`.
2. **Ein Import in einer Funktion ist eine Zeitbombe.** `from ..config import settings`
   lief monatelang nicht auf, weil die Funktion nur aus einem selten genutzten Pfad
   (Gemini-Vision) heraus aufgerufen wird. Modul-Level-Imports scheitern beim Start —
   laut und sofort. Das ist ein Feature.
3. **Unausgefuellte Vorlagen im Repo sind schlimmer als keine Datei.** Sie sehen
   konfiguriert aus.
